# ☁️ CloudSync - Weather App

A beautiful and feature-rich weather application built with Flutter that provides real-time weather updates, 7-day forecasts, and location-based weather tracking.

## 🚀 Live Demo

**[View Live App](https://vinayakpandey14112002.github.io/cloud_sync)**

## 📱 Features

- 🌍 **Real-time Weather** - Get current weather conditions for any location
- 📅 **7-Day Forecast** - Plan ahead with detailed weekly forecast
- 🎯 **Location-based** - Automatic weather detection for your current location
- 🔍 **Search Cities** - Check weather for any city worldwide
- 🌡️ **Detailed Metrics** - Temperature, humidity, wind speed, pressure, and more
- 🌙 **Beautiful UI** - Dynamic backgrounds based on weather conditions
- 📱 **Responsive Design** - Works perfectly on mobile, tablet, and desktop

## 🛠️ Tech Stack

- **Framework:** Flutter & Dart
- **API:** OpenWeatherMap API
- **State Management:** Provider
- **HTTP Client:** Dio
- **Platform:** Web, Android, iOS

## 🏗️ Installation & Setup

### Prerequisites
- Flutter SDK (3.0 or higher)
- Dart (3.0 or higher)
- OpenWeatherMap API key

### Steps to Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/vinayakpandey14112002/cloud_sync.git

# 2. Navigate to project directory
cd cloud_sync

# 3. Get dependencies
flutter pub get

# 4. Add your API key
# Create a .env file and add:
# OPENWEATHER_API_KEY=your_api_key_here

# 5. Run the app
flutter run -d chrome
