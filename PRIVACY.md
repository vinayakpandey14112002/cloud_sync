# Privacy Policy for CloudSync

**Effective Date:** May 07, 2026

## 1. Data Collection
CloudSync does **not** collect, store, or share any personal information from its users. The app requires location access solely to provide accurate weather forecasts for your current area. This location data is used in real-time only and is never saved or transmitted to any server.

## 2. Third-Party Services
To display weather information, CloudSync uses a weather data API. The API provider may receive your approximate location (city-level) to return relevant weather data. No personal identifiers are shared.

## 3. Hosting & GitHub Pages
This privacy policy page is hosted on GitHub Pages, a service provided by GitHub Inc. When you access this page, GitHub may collect standard server logs (e.g., IP address, browser type, request timestamp) for security and operational purposes as described in [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
